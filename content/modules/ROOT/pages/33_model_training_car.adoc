# Model Training

In this module you will sync a git repo of a data science for a fictional insurance application (Parasol), and execute the logic contained in the Jupyter notebooks. 

To perform this task, we will use the workbench/notebook image that we created in the previous module. 

## Steps to create workbench with a custom notebook

. In Red Hat OpenShift AI dashboard, navigate to your user's `workshop` data science project (e.g. `user20-workshop`), and select the `Workbenches` tab

. From the `Workbenches` tab, make sure that your workbench created in previous section is running and open it, so we can start playing with the code 🎮

+
[.bordershadow]
image::03_workbench_running.png[]

. Once in JupyterLab, click on a source code icon of File Browser menu or `Clone a Repository` button in Git and enter repo url to clone the `parasol-insuance` repository from https://github.com/rh-aiservices-bu/parasol-insurance.git

+
[.bordershadow]
image::Git_Clone_Parasol_Insurance.png[]

. Navigate to `parasol-insurance/lab-materials/04` and run the following notebooks one by one:

* 04-01-over-approach.ipynb,
* 04-02-car-recognition.ipynb,
* 04-03-model-retraining.ipynb,
* 04-04-accident-recog.ipynb

It is expected that you execute all the cells in each of the notebooks without errors.
