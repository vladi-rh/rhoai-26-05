# Introduction to Red Hat OpenShift AI (RHOAI) 

Welcome to the Introduction to Red Hat OpenShift AI (RHOAI).
This lab is designed to provide introduction hands-on experience with the RHOAI a platform for workloads with AI/ML capabilities.

Red Hat OpenShift AI is an artificial intelligence (AI) platform that provides tools to rapidly train, serve, and monitor machine learning (ML) models onsite, in the public cloud, or at the edge.

Once you access the RHOAI environment, we will dive deeper into some common use cases:

* Setting up a workbench for experimentation
* Training a ML model 
* Using https://en.wikipedia.org/wiki/Amazon_S3[S3 compatible] storage to save the newly trained model
* Serving the model using a custom inference engine
* Using data science pipelines
